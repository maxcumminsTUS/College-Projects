# College Projects

A collection of projects completed as part of my **Computer Networks & Cybersecurity** course at **Technological University of the Shannon (TUS)**.

## Projects

### Ecommerce

A basic e-commerce website and database project developed to demonstrate how an online store can manage customers, products, shopping carts, orders and payments.

The project uses **PHP and MySQL/SQL** to handle customer registration and login, products, shopping carts, checkout and order confirmation.

**Main areas covered:**

- PHP
- MySQL / SQL
- Database design
- Customer accounts
- Products and shopping carts
- Orders and payments

---

### FootballApp

A C++ console application designed to manage a simple football league.

The application allows users to create teams, view the league table, enter match results and update team statistics such as games played, goals scored, goals conceded and points.

**Main areas covered:**

- C++
- Object-oriented programming
- Classes and objects
- Arrays
- Functions
- Conditional logic
- League and match management

---

### Djibouti

A web development project focused on creating a website about **Djibouti**.

The project uses HTML and CSS to create multiple pages, incorporate images and present information about the country.

**Main areas covered:**

- HTML
- CSS
- Web page structure
- Multiple-page navigation
- Images and media
- Basic website design

---

## Purpose

These projects demonstrate practical programming, database, web development and software development skills developed throughout my college coursework.
